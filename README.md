# Titanic Data Analysis

## Project Overview
An Exploratory Data Analysis (EDA) project on the Titanic dataset to understand the factors affecting passenger survival.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Data Understanding
- Data Cleaning
- Missing Value Analysis
- Feature Engineering
- Age and Gender Analysis
- Pclass and Deck Analysis
- Survival Rate Analysis
- Correlation Analysis
- Data Visualization

## Dataset
The project uses the Titanic passenger dataset containing passenger details, ticket class, age, gender, fare, cabin and survival information.

## Key Insights
- Female passengers had a higher survival rate.
- Passenger class was associated with survival.
- Children showed different survival patterns from older passengers.
- Gender and age together provided more meaningful survival insights.

## Project Structure
- `data/` – Dataset files
- `notebooks/` – Google Colab notebooks

## How to Run
Open the notebook using Google Colab and run the cells sequentially.
